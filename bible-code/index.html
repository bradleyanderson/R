1. Choose your word(s)

Type a word in any language — it's translated to Hebrew automatically and shown faded inside the box, with its gematria (numeric) value alongside. Press Enter to search with everything entered so far and open a fresh box for the next word. You can also type Hebrew letters directly. Add up to 30 words — each gets its own color and label, shown along its line in the grid.

2. Set your search range

"Skip" is how many letters apart each letter of the word is in the raw text (skip 1 = the word as normally written). Larger skip ranges find more matches but take longer to search. Closing this panel — with the handle below or the "🔍 Search" button in the top bar — runs the search with the words currently entered.

After viewing a grid for a searched word, click "🔎 Open search" on the grid toolbar (next to "Find crossing words") to scan the visible grid for other Hebrew words — from a built-in dictionary, not tied to any search tag — that cross your highlighted word's path. Matches are outlined on the grid and listed below with their gematria values.

About this tool

This app searches the consonantal Hebrew text of the Torah (Westminster Leningrad Codex, the same public-domain source text used in Bible code research) for Equidistant Letter Sequences — occurrences of a word's letters spaced an equal number of letters apart, in either direction, anywhere across all five books of the Torah treated as one continuous string of 305,172 letters.

This phenomenon was popularized by Michael Drosnin's book The Bible Code and a 1994 paper by Witztum, Rips, and Rosenberg. It's worth knowing that the statistical claims behind it have been strongly challenged — most notably by Brendan McKay and colleagues, who showed similar "codes" can be found in any sufficiently long text, including War and Peace. With ~300,000 letters and a generous skip range, almost any short word can be found purely by chance.

Text source: Open Scriptures Hebrew Bible (Westminster Leningrad Codex), public domain.
